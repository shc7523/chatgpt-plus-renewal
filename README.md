## 自动续费在哪里管理？怎么取消？

开通路径：登录 ChatGPT，点头像图标 → Upgrade Plan → Get Plus。

续费是自动的，管理入口在：头像图标 → Settings → Account（账户）。这里可以管理订阅、查看发票、取消套餐。注意一个细节：接收发票或收据的邮箱，可能和你登录用的 ChatGPT 账号邮箱不是同一个，找扣款记录时两个邮箱都翻一下。

不想续下个月，就在下一次扣费日期之前取消。刚参加免费试用活动的尤其要记住这一天——以印度 10 月的活动为例，免费期结束后会自动回到每月 1,999 卢比的原价，不想付费就要在活动期内取消订阅，或者关掉已经建立的自动续费指令。

在应用商店内订阅的，续费走的是苹果或谷歌的订阅体系，取消和换绑也要到对应应用商店的订阅管理里操作，网页端的 Settings 里看不到这笔账单。

## 扣了款，账号却还是免费版？按这个顺序排查

这种情况多数不是被坑了，而是登录错了账号。按顺序来：

1. 别急着退出，先在网页端进入 Settings → Account，确认当前登录的账号邮箱，以及它是不是绑定订阅的那个账号。
2. 用 Apple 注册并且开了“隐藏邮箱”的，账号地址可能是 @privaterelay.appleid.com 结尾。登录时选 Continue with Apple，并用当初同一个 Apple 账户。
3. 手机 App 里进 Settings → Restore purchases，同步一次订阅状态。
4. 确认完账号和登录方式后，在显示免费版的那台设备上退出登录，重新登录订阅对应的账号。
5. 还是不行就联系官方支持，附上收据，或提供被扣款卡号的后四位，方便对方定位订阅。

如果认为是扣错了钱，可以申请退款，提交时要用绑定订阅的那个 ChatGPT 账号登录。退款申请通过后，一般 5–10 个工作日退回。
